# ماتيو سيلفا (Mateo Silva)

```text
الموقع:       لشبونة، البرتغال (UTC+0 / WET)
التخصص:      الأنظمة الموزعة، معمارية الأولوية المحلية (Local-First)، بروتوكولات P2P
فلسفة العمل:   برمجيات مرنة تعيش أطول من خوادمها المركزية
المنصب:      مهندس بنية تحتية أول في Distributed Storage Labs
الحالة:       صيانة البروتوكولات المفتوحة وتطوير شبكات الراديو المتداخلة منخفضة الطاقة
```

مرحباً، أنا ماتيو. أقوم بتصميم وبناء برمجيات قادرة على العمل بثبات في ظل أقسى ظروف الشبكات، والروابط غير المستقرة، وبيئات انقطاع الاتصال التام. يتركز معظم عملي حول أنواع البيانات المنسوخة دون تعارض (CRDTs)، وخوارزميات مزامنة الحالة عبر نطاقات ترددية بالغة الضيق، وعفاريت الشبكات (Network Daemons) المدمجة المكتوبة بلغتي Rust و Go.

حين لا أكون منشغلاً بتحليل تخصيص الذاكرة عبر الطرفية أو ضبط خوارزميات التحكم في ازدحام TCP، ستجدني غالباً أمارس ركوب الأمواج على شواطئ كوستا دا كاباريكا، أو أحمص حبوب الإسبريسو المختصة، أو أقوم بتحميض أفلام التصوير التناظري بالأبيض والأسود مقاس 35 مم في غرفتي المظلمة.

---

## 🔭 مجالات التركيز الحالية والأبحاث النشطة

- **مزامنة الأولوية المحلية (Local-First)**: تحسين خوارزميات التوفيق لسجلات الإضافة فقط (Append-only logs) مع حل حتمي للتعارضات دون الحاجة إلى مصدر حقيقة مركزي واحد.
- **شبكات النظير للنظير (P2P) محدودة النطاق**: استكشاف تنسيقات التسلسل فائقة الصغر وآليات تكرار الحالة التفاضلية عبر أجهزة راديو LoRa وتقنية Bluetooth LE.
- **قابلية المراقبة الشبكية على مستوى النواة**: كتابة مجسات تتبع eBPF لرصد قمم زمن انتقال الذيل (Tail Latency) في خطوط أنابيب توجيه الحزم عالية الإنتاجية.
- **التخزين التعاوني غير المتصل**: بناء ملحقات جداول افتراضية بلغة C لقواعد بيانات SQLite لتتبع الساعات المتجهية (Vector Clocks) أصلياً داخل أشجار B-trees.

## 🛠️ أبرز المشاريع مفتوحة المصدر

| المشروع | اللغة | الدور / الحالة | الوصف |
| :--- | :--- | :--- | :--- |
| **`merkle-stream`** | Rust | المنشئ والمشرف | مكتبة غير متزامنة عالية الأداء للتوفيق بين الحالات استناداً إلى أشجار ميركل للشبكات اللاسلكية المتقطعة. |
| **`driftwood-kv`** | Go / WASM | المطور الأساسي | مخزن مفتاح-قيمة مدمج يركز على المعالجة المحلية أولاً مع بدائيات CRDT للحالة وبدون أي قياس عن بُعد سحابي. |
| **`beacon-mesh`** | C99 / Rust | المشرف | عفريت توجيه خفيف الوزن لترحيل الحزم اللامركزي في البيئات المعزولة عبر أجهزة LoRa منخفضة الطاقة. |
| **`polaroid-cli`** | Zig | مشروع شخصي | أداة طرفية سريعة لحساب منحنيات التعريض الضوئي وتحويل المسوحات الضوئية للنيجاتيف التناظري بصيغة RAW. |
| **`sqlite-vclock`** | C / SQLite | المؤلف | ملحق جدول افتراضي لـ SQLite يتيح تتبع الفروع المتزامنة في بيئات الأسياد المتعددين (Multi-Master). |

## 💻 العتاد التقني ومجموعة الأدوات

### لغات البرمجة والبيئات التشغيلية
- **الإنتاج الأساسي**: Rust (tokio, serde, async-std)، و Go (التزامن، netpoll، آليات بيئة التشغيل الداخلية)
- **المستوى المنخفض والأنظمة المدمجة**: C99، و Zig، ولغة تجميع ARM Cortex-M Assembly
- **طبقة الويب والواجهات**: Modern TypeScript، و Svelte، و WebAssembly (Wasm-bindgen)
- **البرمجة النصية وأدوات النظام**: POSIX Shell، و Python (لنمذجة البيانات والمحاكاة العددية)، و Lua

### الأنظمة الموزعة والتخزين
- **هندسة البروتوكولات**: libp2p، و gRPC، و Protobuf، و QUIC، وضبط مكدس TCP/IP للنواة، و WireGuard
- **نماذج النسخ المتماثل**: CRDTs القائمة على الحالة والعمليات، و Merkle DAGs، والساعات المتجهية، وتوافق Raft
- **محركات التخزين**: RocksDB، و LMDB، و SQLite (الجداول الافتراضية، ووضع WAL)، و PostgreSQL

### هندسة النظم والبنية التحتية
- **أنظمة التشغيل**: Linux (Debian, Arch Linux, Alpine)، و FreeBSD
- **التشخيص والتحليل**: eBPF (`bpftrace`, `bcc`)، و `perf`، و `strace`، و Wireshark، و Valgrind
- **الحاويات والنشر**: Docker (المراحل المتعددة وبناء scratch)، و Nix / NixOS، و QEMU / KVM
