Привет, меня зовут Матео. Я проектирую программное обеспечение, способное надежно функционировать в агрессивных сетевых условиях, при нестабильных соединениях и в полностью изолированных средах. Основная часть моей работы посвящена бесконфликтным реплицируемым типам данных (CRDT), алгоритмам синхронизации состояний в сетях с жестко ограниченной пропускной способностью и встроенным сетевым демонам на Rust и Go.

Когда я не профилирую распределение памяти в терминале и не настраиваю параметры управления перегрузкой TCP, меня обычно можно встретить на волнах Кошта-да-Капарика, за обжаркой спешелти-эспрессо или проявкой 35-мм черно-белой пленки в собственной фотолаборатории.

## 🔭 Текущие исследования и проекты

- **Синхронизация Local-First**: Оптимизация алгоритмов сверки логов, работающих только на добавление (append-only), с детерминированным разрешением конфликтов без единого источника истины.
- **Одноранговые сети с ограниченным каналом**: Разработка сверхкомпактных форматов сериализации и дельта-репликации данных для радиомодемов LoRa и Bluetooth LE.
- **Сетевая наблюдаемость уровня ядра**: Написание eBPF-зондов для отслеживания всплесков задержек на хвосте распределения (tail latency) в высоконагруженных конвейерах маршрутизации пакетов.
- **Автономное совместное хранилище**: Создание расширения виртуальных таблиц на C для SQLite, позволяющего нативно отслеживать векторные часы непосредственно в структурах B-деревьев.

## 💻 Технический арсенал

### Языки программирования и среды исполнения
- **Основной рабочий стек**: Rust (tokio, serde, async-std), Go (многопоточность, netpoll, внутренние механизмы рантайма)
- **Низкоуровневая разработка**: C99, Zig, ассемблер ARM Cortex-M
- **Веб и интерфейсы**: Современный TypeScript, Svelte, WebAssembly (Wasm-bindgen)
- **Скрипты и автоматизация**: POSIX Shell, Python (моделирование данных и численные расчеты), Lua

### Распределенные архитектуры и хранение
- **Инженерия протоколов**: libp2p, gRPC, Protobuf, QUIC, тюнинг стека TCP/IP, WireGuard
- **Модели репликации**: State-based и Operation-based CRDT, графы Merkle DAG, векторные часы, консенсус Raft
- **Движки хранения**: RocksDB, LMDB, SQLite (виртуальные таблицы, режим WAL), PostgreSQL

### Системный анализ и инфраструктура
- **Операционные системы**: Linux (Debian, Arch Linux, Alpine), FreeBSD
- **Диагностика и профилирование**: eBPF (`bpftrace`, `bcc`), `perf`, `strace`, Wireshark, Valgrind
- **Контейнеризация и окружения**: Docker (многоэтапные сборки и scratch), Nix / NixOS, QEMU / KVM
